## 环境与数据说明

Anker首届黑客松挑战赛·充电储能赛道

我们已经在**一台云端主机上把储能设备（模拟器）和控制入口（Home Assistant）**都装好、跑起来了，还额外准备了**100 个站点、90 天的历史数据**给你离线练手；你只需要写自己的调度程序，部署在另一台干净的云端主机上，通过标准接口去控制前面那台主机上的设备。

## 01 一台云端主机（环境机）上，已经装好并跑着

### 1) 储能系统 + 负载模拟器

已经跑着 **3 台互相独立的虚拟 Anker SOLIX Solarbank Max AC** 储能设备，对应 **3 个互不相同的真实站点**。每台设备各自产生它那个站点的光伏发电、家庭用电、电池状态数据，也各自接受充放电指令——对你的程序而言，和操作 3 台真机没有区别。

3 台设备之外，同一台主机上还跑着**电价 / 天气 / 评分 / 成绩的数据接口**（单独一个端口，含 3 个站点的数据）。

### 2) Home Assistant (HA) 与 HA 插件

Home Assistant 已经装好并初始化完成——这是你**读设备数据、下发控制指令唯一被允许的入口**，比赛规则要求所有控制必须经它。插件商店 HACS 已装好，官方插件 ha-anker-solix-official（https://github.com/anker-charging/ha-anker-solix-official）已经安装好，用来把 HA 和上面 3 台模拟设备连接起来。

> 你唯一还要手动做一次的事：登录 HA 网页，把这 3 台设备“添加”进去（3 次操作，几分钟搞定）——插件装好不等于设备已连接。

还有一份 SOP：《参赛者 SOP：Anker SOLIX 储能策略黑客松》——完整的环境连接、设备添加、数据接口调用、控制指令下发、评分规则等操作步骤都在里面。本页提到的每一步“怎么做”都可以在其中找到对应章节。

## 02 100 个站点、90 天的训练数据集

**数据结构**：一份可下载的历史数据包，100 个练习站点各一份 CSV，逐小时的光伏发电功率、家庭负载、辐照度、云量、气温，外加同一时刻的买电价/卖电价，覆盖约 90 天。

**口径一致**：电价两列与实时电价接口出自同一张电价表，按时间戳对齐；配合光伏/负载列即可离线回测策略收益，不用占用真实环境，回测口径与正式评分一致。

> 不含什么：这份数据不含电网买卖电量、电池充放电、SOC——那些是策略执行后才产生的结果，需要你自己的程序跑起来后才有。

**用途**：正式上手写代码前，先在本地把“低价充、高价放”这类策略在这 100 个站点上跑一遍，看看能不能省钱，再拿到真实环境里验证。

## 03 你只需要做的事

- 写自己的调度程序（任意语言都可以，能发 HTTP 请求、解析 JSON、写个简单的定时循环即可）。
- 部署在另一台干净的云端主机（参赛机）上，或者直接在自己电脑上跑——两种方式比赛完全等价。
- 程序的工作方式：读环境机上的电价/天气/设备数据 → 计算每个站点的充放电计划 → 通过 HA 把控制指令发回环境机上的设备。

**三者关系**

| 角色 | 说明 |
| --- | --- |
| 你写的程序 | 跑在另一台干净的云端主机（参赛机）或你自己的电脑上，通过 HTTP 读数据 / 下指令 |
| ★ HA + 官方插件 | 跑在环境机上，唯一的合法控制入口 |
| 模拟器 + 数据接口 | 3 台储能设备模拟器 + 电价/天气/评分接口，跑在环境机上，已经跑起来了 |

## 04 在此基础上，你还可以做的事

除了跑通“读数据→下指令”这条最小闭环，鼓励在以下方向上继续加分：

① **调度程序**：把“谷充峰放”这个最小策略，升级成综合考虑电价预测、天气/辐照度预测、SOC 状态的调度算法。规则算法、优化算法、机器学习/强化学习或组合皆可，但要讲清楚为什么这么选，建议先用 100 站点历史数据离线回测。

② **能源统计和看板**：除了模拟器自带的仪表盘，自己可以做一个可视化看板：3 个站点的实时功率流向、SOC 曲线、累计收益、每日峰谷套利效果等，帮助你更快发现策略问题，也是现场演示的加分项。

③ **基于 AI 大模型的充放电可解释**：每一次充放电决策，用大模型生成一句人话解释，并支持追问“为什么不多充一点”，把可解释性本身做成产品体验，让不懂电的人也能看懂并信任这套策略。
