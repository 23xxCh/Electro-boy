## 0. 一页速览

这份手写稿是一套「虚拟家庭环境（Virtual Env, VE）本地模拟」的**设计设想**，围绕四件事：

| # | 主题 | 一句话 |
|---|---|---|
| 1 | 能流图 | 从 1 个站点扩到 3 个站点并可视化；用官方 HA 插件与站点通讯 |
| 2 | 看板 | 省钱指标 / 电能指标 / AI 解释决策 / 智能插座；用官方 HA 做面板 |
| 3 | VE 数据模型 | Site（Weather、SOC…LP、Reward&Details、Appliances）+ Grid Price API + Score |
| 4 | 功率信号模型 | `P_App = TC[ P_work · R_E ]`，由 两组基础信号 组合出 4 种模板波形 |

核心公式：

```
Site_Power = Σ Appliance_Power_i        →   P_site(t) ≜ Σ P_App_i(t)
P_App(t)   = TC[ P_work(t) · R_E(t) ]   →   电器工作功率信号 R_A = R_P · R_E
```

## 3. Appliances（家电设备）

- 一个 site 中可以有**多个 Appliance**；**产品叙事中，考虑用智能插座获取、控制电器**
- Appliance 由 **4 个属性**描述：

| # | 属性 | 含义 | 可见性 / 备注 |
|---|---|---|---|
| ① | **Name** | 可个性化的命名 | private |
| ② | **Power** | 实时功率 | private；**对外可读值 = 当前时段的平均功率**（按「时隙」切片）；**only read** |
| ③ | **Importance** | 优先级 | public |
| ④ | **使 / 失能** | 可控开关 | public |

**Power 的用途**：

- 用于**功率检测**与**异常判断**
- 方法：取在 **工作时**的 power curve，用**时序统计**方法对比 **当前（now）** 与 **以往（before）**
- 触发条件：`if (enable)` 则做 **power Analysis**

## 4. 功率信号模型（核心数学部分）

### 4.1 站点功率合成

```
Site_Power = Σ_{i=1..N} Appliance_Power_i
⟹  P_site(t) ≜ Σ_{i=1..N} P_App_i(t)
```

### 4.2 单设备功率 = 工作功率 × 使能

```
P_App(t) = TC[ P_work(t) · R_E(t) ]
```

- **`TC(·)`**：原注「为T型曲线加减速函数，输入一段信号，参考工作使能信号，在上升沿和下降沿处各留出占一个周期5%的斜坡信号，斜坡信号的斜率作为P_App(t)的一个固定参数」
- **`P_work(t)`**：工作功率信号
- **`R_E(t)`**：工作使能信号

### 4.3 `P_work(t)` 有两种设计（参数可调）

| 序号 | 名称 | 波形 | 公式 |
|---|---|---|---|
| ① | **阶跃信号** | 0 → A 的跳变 | `P_w(t) = { 0, t≤0 ; A, t>0 }` |
| ② | **正弦信号** | 绕 `B` 上下摆动的正弦（振幅 A，角频率ω） | `P_w(t) = { A·sin(ωt) + B, t>0 ; 0, t≤0 }` |

> 轴标注：`P`、`A`、`B+A`、`B`、`B-A`、`time slot`、`t`

### 4.4 `R_E(t)` 有两种设计（参数可调）

| 序号 | 名称 | 波形 | 公式 | 含义 |
|---|---|---|---|---|
| ① | **阶跃信号** | On 之后一直保持 | `r_E(t) = { 1, t>0 ; 0, t≤0 }` | 原注「**不停工作**」 |
| ② | **方波信号** | 周期通断 | `r_E(t) = { 1, kT ≤ t < kT+DT ; 0, kT+DT ≤ t < (k+1)T }` | `T` 为周期，`D` 为占空比 |

> 轴标注：`E/U`、`On`、`Off`、`t`

### 4.5 四种模板功率信号

两组设计组合，得到**四种模板**：

```
P_App(t)  = TC[ P_w(t) · R_E(t) ]
P_Site(t) = Σ_{i=0..n} P_App_i(t)
```

四个模板波形（对应第 4 页的四张草图）：

| # | 波形形态 | 轴标注 | 说明 |
|---|---|---|---|
| 1 | **阻尼振荡型** | `A+B`、`B`、`-A+B` | 绕 `B` 做衰减振荡，最终收敛到 `B` |
| 2 | **上升稳定型** | `A` | 快速上升后稳定在 `A`（类似充电曲线） |
| 3 | **波形脉冲串** | `B+A`、`B`、`B-A` | 重复的「缓升–带波动平台–缓降」脉冲 |
| 4 | **矩形脉冲串** | `A` | 重复的矩形脉冲，幅值 `A` |

> **圈注（红笔）**：`3 个站点` 各设 `4 种设备`，`参数 随机`（第 2 行首字字迹难辨，疑为「参数/数据」）

**P_work(t)中的A、B、ω，R_e(t)中的T、D，TC(·)中的斜坡信号斜率、上升时间下降时间都属于P_App(t)的固定参数，换句话说，一个设备在完成P_work和R_enable这两个信号的选择后，可以通过对应的信号参数唯一确定这个设备，我们对于每个站点的每个设备都取一组合理的随机参数，就可以模拟不同站点不同设备的功率情况了，虽然它们叠加后图像上十分相似，但是信号不是同一个，同样的我们通过线性叠加一个站点内所有的功率曲线，就可以得到这个站点的功率曲线了；后续我们如果想要模拟设备故障的功率信号，就可以向这些基频信号（P_work和R_enable）中混入一些扰动信号**

## 5. 系统架构

### 5.1 与 HA 的接口（「模拟 HA 接口」）

```
模拟 HA 接口：
    请求 request  ──HTTP──▶  [ HA ]
    数据 data     ◀──HTTP──  [ HA ]
```

即：**用 HTTP 模拟 HA 的请求/数据接口**，向上屏蔽真实 HA。

### 5.2 主链路

```
[ Controller { model } ]  ──(order) request──▶  [ Virtual Env ]  ──(request)──▶  [ Vision Panel ]
          ▲                        │                    │                             │
          │                   data / state          data                         看板 / 能流 / 解释
          └──── gain report ─────┴────────────────────┴─────────────────────────────┘
          └──── decision report ──────────────────────┘
```

- 四段链路：**Controller（含 model） → Virtual Env → Vision Panel**
- **`gain report`**：由 Vision Panel 回传给 Controller（红笔大弧线）
- **`decision report`**：由 Controller 输出（红笔下弧线）
- **Vision Panel** 对外给三样东西：**看板**、**能流**、**解释**
- 实现方式二选一：**基于 HA 实现**，**or 模拟 HA 的实现**

### 5.3 VE 的 UI 要有什么

> VE 的 UI 要有什么？

UI 只需三块：

- **Site info**
- **GP API**（Grid Price API）
- **Score**

## 6. 更细的信号定义（第 6 页）

- 时间区间：`t ∈ [t_s, t_e]`
- 纵轴单位：`P /kWh`

### 6.1 基础信号

**方波信号**

```
r(t) = { A,  t_s < t < t_e
       { 0,  t ∈ (-∞, t_s) ∪ (t_e, ∞)
```

**正弦信号（振幅、频率）**

```
r(t) = { A·sin(ωt) + B,  t ∈ [t_s, t_e]
       { 0,              t ∈ (-∞, t_s) ∪ (t_e, ∞)
```

> 分量标注：`A·sin(ωt)` 为**振荡分量**，`B` 为**基本分量**

### 6.2 使能信号（Enable or Unable）

> **`Appliance_Power` 的信号模板由「工作功率」和「工作时间」共同决定**

| 模式 | 名称 | 公式 | 原注 |
|---|---|---|---|
| mode 1 | **间歇** | `r(t) = { 1, t_s < t < t_e ; 0, ... }`（有周期） | 间歇 |
| mode 2 | **不停** | `r(t) = 1(t)`（阶跃信号） | 不停 |

> 轴标注：`On`、`Off`、`time slot`、`周期`

### 6.3 合成与工程细节

```
功率信号 R_P  ·  使能信号 R_E  =  电器工作功率信号 R_A
         R_P · R_E = R_A
```

- **考虑功率上升 & 下降各占 `Work Time` 的 5%**（即给矩形/梯形脉冲加上平滑过渡段）
- **圈注（红笔）**：`2 阶` / **引入加速度信号**；旁侧另有小字标注（疑为「…阶跃信号」）
- 页面底部两张草图：左侧是「尖峰 + 衰减振荡 + 间歇爆发」的真实功率曲线，右侧是「平滑上升–平台–平滑下降」的梯形脉冲
