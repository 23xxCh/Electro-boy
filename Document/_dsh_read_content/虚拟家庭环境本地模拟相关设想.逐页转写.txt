                                    Δ
    Site_Power = Σ_{i=1..N} Appliance_Power_i   ==>  且  P_site(t) ≜ Σ_{i=1..N} P_App_i(t)

    P_App(t) = R_E · P_work(t) · R_E(t)

    P_App(t) = TC[ P_work(t) · R_E(t) ]        〔此处画了一个星号，表示重点〕

    其中，TC 为 TC(·) 为 T 型的〔?〕函数。      〔难辨，疑为「减速函数 / 衰减函数」〕
          P_work(t) 为 工作功率信号
          R_E(t)   为 工作使能信号

    P_work(t) 有两种设计，参数可以〔?〕        〔难辨，疑为「累死」〕

        ① 方波信号                   ② 阶跃信号
            P                            P
            |  A  +----+                 |      ________
            |     |    |                 |     |
            |     |    |                 |     |
            +-----+----+--> t            +-----+----------> t
                  time slot
                                         P_w(t) = { 0 , t <= 0
                                                  { 1 , t > 0

        ③ 正弦信号   P
                     |    ___
                  B+A|   /   \
                     |  /     \
                   B |--+       \      /--
                     |           \    /
                  B-A|            \__/
                     +----------------------> t

                     P_w(t) = { A·sin(ωt) + B , t > 0
                              { 0             , t <= 0

    R_E(t) 有两种设计，参数可以〔?〕        〔难辨，疑为「累死」〕

        ① 阶跃信号                    ② 方波信号
              E/U                            E/U
               |  On ___________              |  On  _   _   _
               |                              |     | | | | | |
               |                              |     | | | | | |
               |  Off                         |  Off
               +---------------> t            +---------------> t
               〔红笔旁注：不停工作〕

            r_E(t) = { 1 , t > 0           r_E(t) = { 1 , kT <= t < kT + DT
                     { 0 , t <= 0                   { 0 , kT + DT <= t < (k+1)T

                                            T 为周期，D 为占空比。
