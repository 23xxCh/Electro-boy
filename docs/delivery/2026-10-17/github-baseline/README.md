# Current-project GitHub baseline

This publication snapshots the reviewed existing project before subsequent feature work. It preserves the remote legacy VE/Controller files and the two local governance commits. The current App, shared Web/Feishu Agent, persistent-memory code, local single-household runtime, default-disabled environment reader and essential assets are added under their existing workspace paths.

## Included and excluded

`source-manifest.json` records every exported source path, original hash and public-copy hash. Three Simulator configuration copies have authentication defaults emptied. No token file, private credential, personal memory/database, HA runtime directory, raw execution receipt, training archive, video, dependency directory or nested repository is exported.

The minimal numerical dependency set includes four existing `.pt` checkpoints: site-1 PV, site-1 load and two load-window encoders. Their presence/hashes are checked; this publication does not execute them. The historical UI retains report-4 (672 XML per site), three mock CSV files and the frozen FV comparison JSON. These are distinct from current-device observations and real household profit.

The generated Lux3D house GLB, illustration and provenance are included. Credentials and signed provider URLs are absent. No new binary PDF, ZIP or executable is added; existing remote documents remain preserved.

## Checks

- `secret-scan.json`: staged/unignored candidate file paths, secret-format/AST candidates and explicit synthetic-fixture classifications. Matched values are never reported.
- `candidate-manifest.json`: publishable file sizes/hashes, excluding its two self-referential manifest/scan reports.
- `verification.json`: focused socket/process-denied Python suites, static Python parsing, frozen FV validation, 2016 historical XML parses, four checkpoint-presence checks and GLB structure.
- `frontend-build.json`: clean dependency-install and production-build result, recorded after completion.

Python versions are pinned in `Anker_ChargingAndEnergyStorage/requirements.txt`; SciPy is fixed because the existing solver uses a private `_highspy` API. The observed Windows Python environment used the CPU build of torch 2.11.0. The exported requirement names its public release, not a machine-specific wheel URL; installing a different platform wheel is not separately validated here.

## Boundaries

The environment-machine adapter is an offline candidate, default disabled, with remote dispatch blocked. Private local HA setup, official-plugin installation/mappings, credentials and user pairing are external prerequisites. Source publication and offline checks do not prove device connectivity, control, next-tick settlement, browser usability or production deployment.

Opaque inherited PDFs/model/image binaries are not certified secret-free by text-pattern scanning. New binary additions are limited to the named reviewed checkpoints and generated visual assets; their SHA hashes preserve provenance. No environment-machine, HA, Feishu or model API is contacted by this publication task.

The root agent has approved this frozen candidate. Its publication identifiers are branch `publish/current-project-20261017` and tag `baseline-20261017`, using a normal PR merge into main. Subsequent product changes should use separate PRs.
